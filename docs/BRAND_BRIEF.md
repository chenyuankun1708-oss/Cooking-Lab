## Product personality

产品应更接近：

- curious
- warm
- fresh
- knowledgeable
- calm
- human
- non-judgmental

产品应避免被感知为：

- clinical
- fitness-only
- diet app
- SaaS dashboard
- luxury restaurant
- food delivery app

## Emotional goal

用户打开产品时，理想的第一感觉应该是：

“今天想做点好吃的。”

而不是：

“我要填写一个营养计算表。”

因此，产品需要同时保留：

- recommendation 的可靠与可解释
- recipe / story / technique 的内容深度
- 更轻松、更生活化、更有食欲的视觉入口

## Directional summary

当前已形成三套候选方向：

### A. Fresh Editorial

- 食物摄影为主
- 杂志感、自然留白、现代排版
- 强调食材与料理本身

### B. Warm Companion

- 温暖、家庭感、生活感
- 适合未来加入 companion / household 叙事
- 亲近但不能幼稚

### C. Modern Culinary Lab

- 保留料理科学与解释性
- 去掉 dashboard / SaaS 外观
- 更像现代料理工作室或 editorial lab

## Visual principles

- food-first
- ingredient-led
- appetite before metrics
- discovery over control-panel feeling
- calm confidence over marketing spectacle
- cultural texture without invented history

## UI direction

下一版 UI 应减少：

- dashboard 感
- dense metrics first
- engineering interface
- “左侧控件墙 + 右侧结果板”式结构

下一版 UI 应增加：

- food photography
- clearer visual hierarchy
- browse / learn / discover 路径
- story-led blocks
- 更自然的留白与节奏

推荐引擎仍然是核心能力，但不再作为首页唯一视觉主角。

## Photography principle

图片系统应优先服务“真实可做、真实想吃”的感受：

- 新鲜
- 自然
- 明亮
- 有食欲
- 食材纹理清楚
- 自然光优先
- 少量摆盘
- 生活化
- 不油腻
- 不过度滤镜
- 不明显 stock 感

## Naming principle

当前只探索命名方向，不定最终名字。

命名方向包括：

1. 中文自然系
2. 中文陪伴系
3. 中文料理 / 知识系
4. 国际品牌系
5. 中英混合系

## Mobile and accessibility

- 首页结构必须能自然下沉到移动端单列长滚动
- 视觉系统不能依赖 desktop dashboard 布局
- 不用低对比、小字号和仅靠颜色表达信息
- 图片与文字都要服务可读性，而不是只追求氛围

## Future IP

未来可以考虑 mascot、cooking companion、narrator voice 或 household assistant，但当前阶段先建立品牌 voice 和摄影语言，再决定是否引入角色。
