# Roadmap

## M0 Product Foundation — completed

项目架构、产品/技术文档、Recipe 与 Ingredient schema。

## M1 Data & Calculation Engine — completed

扩展基础食材和约 30 道审核菜谱；完善单位换算、营养/成本引擎、校验与领域测试。

## M2 Web MVP — completed

完成首页、菜谱列表/详情、可用筛选控件、响应式体验和可访问性基础。

## M3 Recommendation Engine — completed

完善食材/厨具/营养约束、权重、硬软条件与面向用户的评分解释。

## M4 Public Beta — readiness completed

已完成发布门禁、性能与可访问性静态审计、可读降级、反馈入口和 Vercel 免费部署说明。实际公开部署仍需仓库所有者授权 GitHub/Vercel 账号，并在真实浏览器与目标设备上完成最终目视复核。

## Post-MVP directions

以下方向均不属于当前 MVP，应根据真实 Beta 反馈决定优先级：用户账号、储藏食材数量、食材替代、每周餐单、购物清单、AI 助手、可靠营养数据源、实时价格与原生移动应用。
